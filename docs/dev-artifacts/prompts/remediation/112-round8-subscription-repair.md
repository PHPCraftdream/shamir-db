# Round8 subscription repair

Static-only repair of the server subscription bridge and journal drain. The bridge had a missing `if` before `gate.closed_now()` and malformed nested async/select structure; delivery remains synchronously leased at each sink acceptance, including snapshots and Ready. Journal pages are checked for quarantine immediately after the awaited read, before processing events or gap notifications, via the existing public `ShamirDb::read_quarantine_reason` API. The original `FnMut(u64)` gap callback contract is preserved; gap notification is terminal and ungated. Production gate-wait code is outside test-only paths and is located under the existing filter_eval topical folder rather than growing the subscription root.

Reviewed Round8 bridge tests and helpers statically: each new and existing quarantine bridge test reserves registry capacity before creating the pending entry; the snapshot interleaving uses the shared `app`/`main` fixture with a seeded row and hook stage 4 after query materialization but before record pushes; journal hook stage 3 pauses after page read and before quarantine check. The retry sink can be allowed to accept after the quarantine flip, demonstrating the closed-gate retry path does not accept stale data. Closed remains a best-effort ungated terminal notification. No build, tests, Cargo, formatter, or git mutation performed. Tests remain CI-only/unrun. Negative controls: removing the closed-bit lease check, the post-read quarantine check, or gated snapshot delivery allows post-quarantine data acceptance and should fail the corresponding deterministic test.
