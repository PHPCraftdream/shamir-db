# Round8 integration remediation

Integrated the Round8 quarantine-read, receiver revocation, replication pull, and subscription bridge changes in this worktree. The facade receiver gate now uses one SeqCst CAS state containing a closed bit and active lease count; gate leases are panic-safe via RAII, closure is observable/wakes receivers, and terminal transitions wait for in-flight acceptance leases. Registry entries are weak references and are pruned while taking snapshots so old receiver handles do not accumulate strongly.

The cache keeps add-before-prune publication and its healthy probe uses Acquire; cache refresh errors are propagated by admin call sites. Quarantine transitions publish the relevant cache entries and revoke/drain receivers before durable marker persistence. Bridge event/snapshot/control pushes go through the delivery gate, cancellation races bridge work against gate closure, and terminal Closed remains best-effort. Added deterministic wire long-poll and bridge delivery/snapshot interleaving coverage; retained raw Tokio broadcast receiver compatibility through the JournalReceiver abstraction.
