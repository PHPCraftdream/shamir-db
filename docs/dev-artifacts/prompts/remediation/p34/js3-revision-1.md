2. `core/types/connection.ts:102`: `ConnectOptions` was changed from the SCRAM interface into a union. Existing SCRAM callers break (Node: `const c: ShamirClient = await connect(o)` no longer compiles; browser: no overload accepts `ConnectOptions`; `o.host` becomes `string | undefined`). Restore `export interface ConnectOptions {...SCRAM...}` exactly as on master, add `export type ScramConnectOptions = ConnectOptions`, rename the token-only types (e.g. `NodeTokenConnectOptions`, `BrowserTokenConnectOptions`, with the `never` guards as now), and define `NodeConnectOptions = ScramConnectOptions | NodeTokenConnectOptions` and `BrowserConnectOptions = ScramConnectOptions | BrowserTokenConnectOptions`. The last overload of each entry takes `Node/BrowserConnectOptions`.
3. `browser.ts:19-21`: add the final overload `export function connect(opts: ScramConnectOptions | BrowserTokenConnectOptions): Promise<ShamirClient | PublicBrowserTokenClient>;` (as Node has in `index.ts:21`) so `Parameters<typeof connect>[0]` and `ReturnType` stay sane for SCRAM users.
4. `platform/connect/node-connect.ts:8` and `browser-connect.ts:8`: the public return type is the internal `TokenWsClientImpl` (exposes `terminalController`, raw `tx*` handles, `runTransaction`, `cursor(db,...)`, `runLive(db,...)`). Introduce `export interface TokenWsClient` (own file under `entry/ws/`) with `channel: 'ws'`, `sid`, `expiresAtNs`, `ping`, `execute`, `executeWithTouch`, `waitForVisibility`, `getDdlOpStatus`, `db(name): TokenWsDb`, `close()` per JS0 lines 56-59, and `PublicTokenClient = TokenHttpClient | TokenWsClient`. The Impl must be assignable to the interface; do not change its bodies beyond that.
5. Per-channel overloads (JS0 lines 28-29, 33-34) in `index.ts` and `browser.ts`: before the generic token overload add overloads on `NodeTokenConnectOptions & ({ channel: 'ws' } | { url: \`ws://${string}\` | \`wss://${string}\` })` returning `Promise<TokenWsClient>` and the HTTP counterpart returning `Promise<TokenHttpClient>`; same in the browser entry. Mind overload ordering so SCRAM literals still pick overload 1.

Export the token client types from both entries (`export type {...}` in `index.ts:53-56` and `browser.ts:31-34`): `PublicTokenClient` (browser variant for the browser), `TokenHttpClient`, `TokenWsClient`, `TokenHttpDb`, `TokenWsDb`, `TokenLiveResult`, `TokenLiveSubscription`, `TokenTransactionContext`.
