## Items (all four, in this order)

1. **Test the `Denied` paths in the executor.** The REST executor classifies each request with the scope classifier (`scope.rs`) and answers `Denied` variants with a typed status; only the allowed paths and a handler double are covered today. Add unit tests in the existing executor test tree that drive each `Denied` variant (including the four token-admin variants `CreateApiToken`, `ListApiTokens`, `RevokeApiToken`, `RevokeUserTokens`, and the WS-only paths) through the production dispatch and assert status, body shape and that no handler is invoked and nothing is audited as success.
2. **`exposure_dropped` on serialization failure.** When serializing an exposure notice for the maintenance channel fails, the drop must be counted (`exposure_dropped`) instead of silently lost. Fix in `http_rest/maintenance.rs` (or its producer) and add the test in `maintenance_tests.rs` with an injected failing serialization.
3. **Connection drain with its own budget.** `serve` (and `serve_with_login` / `serve_with_ws` / `serve_with_routes`) drain open connection tasks on shutdown using the caller's remaining budget, which lets one slow connection consume the whole listener drain. Give the transport its own bounded drain budget (a field of the serve config with a conservative default, documented), keep the existing behavior for callers that do not set it, cancel the stragglers after the budget and log them once. Add a transport test with a connection that never finishes and assert shutdown returns within budget (use paused time or short real durations; no `sleep`-polling of production code).
4. **`seed_owner` in e2e.** The e2e harness seeds the token owner through ad-hoc code in several launch helpers. Add a single `seed_owner` helper in `tests/e2e/http_rest/common.rs` (create the owner principal, grant `db://default` and `default/main` as `grant_default_main_access` does, return the owner id) and use it from the existing launchers and from `http_ws` / `http_login` e2e helpers where they duplicate it. Behavior of the tests must not change.
