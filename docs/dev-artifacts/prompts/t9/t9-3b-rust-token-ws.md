# T9-3b - Rust client: token over the native WebSocket (`Client::connect_token_ws`)

Base: branch `feat/t9-3a-replay` (master with R1-R3, T9-2 and the T9-3a token REST client: `TokenEndpoint`, `TokenTrust`, `ApiToken`, `TokenHttpOptions`, the WebPKI rustls connector in `client/transport/token/tls.rs`, hyper http1 helpers in `http_conn.rs`). Design: `docs/dev-artifacts/audits/2026-11-04-t9-client-matrix/DESIGN-T9-3.md` sections 0, 1, 4, 5 and 7 (T9-3b); read it first, then the R1-R3, T9-2 and T9-3a reports at the end of `DESIGN.md`, then CLAUDE.md. Crate: `crates/shamir-client`. Server and other crates do not change. Password login (T9-4) is NOT part of this task.

## Goal

A normal `Client` (same data plane: `execute`, subscriptions, cursors, transactions) that authenticates with an API token over the server's native token WebSocket (`kind: http` listener, `GET /shamir/v1/ws`, binding mode none, no SCRAM):

```rust
Client::connect_token_ws(opts: TokenWsOptions) -> Result<Client, ClientError>
Client::auth_kind(&self) -> AuthKind              // #[non_exhaustive] enum AuthKind { Scram, Token }
```

`TokenWsOptions` (new, `#[non_exhaustive]`, constructor like `TokenHttpOptions::new`): `endpoint: TokenEndpoint`, `token: ApiToken`, `connect_timeout`, `handshake_timeout`, `request_timeout`. Put it next to `TokenHttpOptions` in `session/token/options.rs`; re-export from `lib.rs` together with `AuthKind`.

## What to build (follow the design; deviations only with a written reason in the report)

1. **Upgrade through hyper, never through tungstenite's client handshake** (tungstenite logs the whole request, including `Authorization`, at trace level): TCP + TLS (reuse the T9-3a connector, WebPKI trust, no Ed25519 pin, no `AppLayerServerAuth`) -> `hyper::client::conn::http1::handshake` with `conn.with_upgrades()` spawned -> `GET /shamir/v1/ws` with `Host`, the sensitive `Authorization` header built exactly like the REST client does, `Connection: Upgrade`, `Upgrade: websocket`, `Sec-WebSocket-Version: 13`, `Sec-WebSocket-Key` from `tokio_tungstenite::tungstenite::handshake::client::generate_key()`, exactly one `Sec-WebSocket-Protocol: shamir-v1`, NO `Origin`. File: `client/transport/token/dial_ws.rs`. A non-101 answer maps through the existing status mapper of T9-3a (403 with a `DbResponse::Error` body -> `ClientError::Db`; 401 -> `Http { status: 401, .. }`; 503 with `Retry-After` -> `Http { .. retry_after }`); read at most 64 KiB of body. On 101 verify `Sec-WebSocket-Accept == tungstenite::handshake::derive_accept_key(key)`, the subprotocol equals `shamir-v1`, and there is no `Sec-WebSocket-Extensions`; then `hyper::upgrade::on(response)` -> `TokioIo` -> `WebSocketStream::from_raw_socket(.., Role::Client, Some(config))` with `max_message_size = max_frame_size = MAX_FRAME_SIZE_DEFAULT`. Look at how T9-2's `dial_ws.rs` builds the config and copy it.
2. **First server message = binding frame**, read within `handshake_timeout`: msgpack map with exactly the keys `ok` (true), `sid` (32-byte non-zero bin), `expires_at_ns` (> 0); unknown keys or trailing bytes are an error; a `Close` frame instead -> `ClientError::ConnectionClosed(CloseCause::PeerClosed { code, reason })`; TEXT or anything else -> `ClientError::Protocol`. Decoder in `client/handshake/bearer.rs` (pure function + its unit tests; the server's frame is built in `crates/shamir-server/src/sync/connection/token_ws/binding.rs`, read it). 
3. **Raw framing in `WsByteStream`**: add a mode `WsFraming::{Prefixed, Raw}` (default `Prefixed`; the T9-2 behaviour and tests stay byte for byte). `Raw`: on write, buffer until a complete `[u32_be len][payload]` is present and send ONLY `payload` as one BINARY message; on read, each BINARY message `b` is served as `len_be(b.len()) ++ b` (empty or larger than `MAX_FRAME_SIZE_DEFAULT` -> `InvalidData`); `Close(Some(frame))` -> deliver once an `io::Error` (`ConnectionAborted`) whose inner error is a small `pub(crate)` type `WsPeerClose { code: u16, reason: Arc<str> }` (reason cut to 123 bytes, printable ASCII only), then EOF. Constructor `WsByteStream::raw(ws)`.
4. **Close cause**: add `CloseCause::PeerClosed { code: u16, reason: Arc<str> }` (`CloseCause` is `non_exhaustive`) and in `reader_task` (`client/session/mux/reader.rs`, the `FrameError::Io(e)` branch) downcast `e.get_ref()` to `WsPeerClose` and map it. Check how the existing code maps other causes (`PeerEof` etc.) and keep their behaviour. Document the codes: 4003 no pong, 4010 sid mismatch, 4011 revoked, 4012 expired, 1013 busy, 1000 normal.
5. **Write side**: `WriteSink::TokenWs(WriteHalf<WsByteStream<TokioIo<Upgraded>>>)` with the same delegating `AsyncWrite` as the other variants.
6. **`AuthKind` in `Client`**: `SessionMeta` and `Client` get a field `auth: AuthKind` (crate-internal visibility, public API unchanged); existing constructors set `Scram`; the token session sets `session_id = sid`, `pinned_hash = [0; 32]`, no resumption ticket, `server_query_version = 0`, `request_timeout` from the options. `Client::auth_kind()` getter in `api.rs`.
7. **Local refusal on token sessions**, BEFORE any HMAC tag or body is built (a password of `create_scram_user` must never reach the network): `create_api_token`, `list_api_tokens`, `revoke_api_token`, `revoke_user_tokens`, `create_scram_user`, `set_replicator`, `repl` return `ClientError::Db { code: "token_request_denied", message: "requires a SCRAM session" }` (check the exact `Db` variant shape in `error.rs`). One helper `require_scram(&self) -> Result<(), ClientError>` in `session/client.rs` and one line at the top of each method in `api.rs` (the file is 902 lines: stay below 1000). `server_pub_key_pin()` returns zeros and `resumption_ticket()` `None` on a token session; say so in their docs.
8. **Entry point** `Client::connect_token_ws` in `client/session/entry_ws.rs` (166 lines; keep it below 400, or put it in a new `entry_token.rs` if it grows): timeouts as in the TCP twins (`connect_timeout` for TCP, `handshake_timeout` around TLS + upgrade + binding frame), then dial -> binding decode -> `split(WsByteStream::raw(ws))` -> `Client::assemble(.., WriteSink::TokenWs(w), meta)`.
