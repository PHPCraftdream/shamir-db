## Рекомендация

Резать тег `v0.1.0-alpha.1`, а не открывать новый фронт — все объявленные
NO-GO закрыты, CI зелёный, дальнейшая отсрочка только увеличивает объём под
release drill.

### Шаги до тега

1. Поправить дату заголовка секции `## [0.1.0-alpha.1]` в `CHANGELOG.md`
   (сейчас `2026-08-07`, должна отражать фактическую дату закрытия).
2. **#1022 release drill** (оператор, не делегируется):
   - решить состав публикации: server-only vs server+SDK (все crates сейчас
     `publish = false`, TS `private: true`);
   - матрица совместимости server↔protocol↔clients в release notes, если
     клиенты публикуются;
   - `THIRD_PARTY_LICENSES` — в корне репозитория отсутствует, проверить,
     генерируется ли внутрь релизных архивов;
   - ручной drill на замороженном SHA: backup→restore→verify, прерывание
     DDL в каждой durable-фазе, распаковка архивов на чистой машине.
3. Тег `v0.1.0-alpha.1` → `release.yml` (8 gate-джоб).

### После тега — приоритет

1. **#1024** — `SelectItem::Expression` живёт в wire/parser, executor
   отвергает. Дешёвая мёртвая поверхность контракта — дороже убирать после
   API freeze, чем сейчас. Решить: реализовать вычисляемые проекции либо
   убрать из публичного контракта.
2. **Movement C («I» — Interconnected)** — единственная незакрытая буква
   S.H.A.M.I.R. Фундамент готов полностью: changefeed с event version ==
   `commit_version`, `ChangesSince` one-shot query, durable journal +
   watermark + gap signal, duplex transport + rid-demux, дизайн
   субписок (#201) уже написан. Лестница: network changefeed →
   live subscriptions/server-push → leader-follower replication →
   P2P/gossip.
3. **#1026** — PERF-зонтик (streaming results — главный memory/latency
   потолок). Декомпозировать при взятии в работу, снять baseline-матрицу
   (включая Windows отдельно) перед оптимизацией.
