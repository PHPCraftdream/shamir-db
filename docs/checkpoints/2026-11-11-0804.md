## Decisions

- Версии системной части: штамп формата (эпоха) в каталоге данных, отказ запуска на более новой эпохе, миграция только по явной команде, откат только восстановлением копии; пользовательская часть — журнал миграций схемы приложения в базе. Эпоха поднимается при любом изменении, после которого старый бинарник мог бы испортить данные при записи.
- Шифрование на диске не делаем; копии и экспорт шифруются конвертно, имена файлов и манифест внутри зашифрованной части; режим «открытый ключ получателя» требует новой зависимости — решение владельца.
- Стадия 3 ссылок: guard `when` через `value_nav/type_of` (+ диапазон для i32) на каждую операцию со ссылкой и проверка `skipped` после каждого `db_execute` модуля со ссылками; движок не менялся; модули без ссылок байт-идентичны.
- Видимость каталога сигнатур при компиляции — Execute компилирующего актора (не эффективного Definer), единый текст отказа для «нет цели» и «нет права».
- `save_function` заменяет строку целиком (delete+insert в одной транзакции) вместо слияния полей, чтобы подпись и другие поля не переживали замену.
