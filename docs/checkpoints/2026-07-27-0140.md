## Decisions

- **F-33's architecture**: memory-primary + allowlisted durable mirror (`MirroredStore`) plus a new opt-in `BoxRepoFactory::Hybrid` variant, chosen over @oh's own design report's rejected alternatives (routing all of `__info__` to disk wholesale — persists stale derived state; a routing-composite store keyed purely by byte-prefix — fragile, an `index_id == 0` posting key collides with the system-record prefix; splitting `__info__` into a brand-new `__meta__` store — architecturally cleaner but requires an on-disk layout migration, disproportionate for this problem).
- **`__interner__` gets an allow-ALL classifier**, not the same `is_durable_table_config` allowlist `__info__` uses — this is the single most safety-critical design decision in the whole campaign (index definitions reference interned ids; losing the interner without losing the index defs, or vice versa, is silent corruption, not a loud failure).
- **Hybrid mode is strictly opt-in** — `BoxRepoFactory::in_memory()`'s existing default behavior is untouched (used in ~400 call sites; also structurally impossible for a repo with no writable `data_root`).
