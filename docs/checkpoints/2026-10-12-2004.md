## Decisions
- chose to keep seed refusals as the only new terminal-state persistence (`ReplError::Seed`), restoring the previous `ApplyRejected` resync routing, over the agent's broader change, because it was out of scope and changes recovery semantics.
- chose to box the per-op future in `QueryRunner::run` and the implicit-commit future over raising any stack limit, because debug-build async frames were the cause of four stack overflows and the boxes cost one allocation only on writes/tx ops.
- chose to update the two VIS-3 "rejected before writes" tests to the lifted semantics (implicit outer + nested bounded override now commits with receipts) while keeping the fail-closed test for a nested override inside a TRANSACTIONAL outer, over deleting them, to keep the remaining fail-closed contract covered.
- chose a public `replication_seed::install_with` fault-injection seam (production passes a no-op closure) over a hidden cfg(test) hook, because the e2e target is a separate crate that must interrupt an install mid-flight.
- chose a bounded retry in the e2e `connect` helper (5 attempts, child log tail on failure) over a bigger timeout, because a dropped handshake on a CPU-starved macOS runner is transient while a dead server must still fail loudly with its own log.
